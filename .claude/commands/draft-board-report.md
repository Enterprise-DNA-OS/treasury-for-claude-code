---
description: Draft the monthly treasury report for the board from the records: cash, the 13 weeks, facilities, covenants, FX cover, counterparties and policy exceptions.
---

1. Run `npm run treasury --silent -- draft-board-report`. It writes `drafts/treasury-report-<date>.md`.
2. Read the draft back, add two or three lines of commentary on what moved and why, and tell the operator where it is. Never send it.
3. For a branded page per entity run `npm run docs -- treasury-report`.
